Research method

Healthcare That Works

The flagship research franchise asks a deliberately practical question: which health-system mechanisms produce reliable care, and can those mechanisms survive Sierra Leone’s real constraints?

Framework

The research question

For each country or model, we examine what the system is trying to accomplish, how responsibility is organized, how people enter care, how prevention is built in, how referrals work, how information returns, how the workforce is supported, how care is financed and how the system learns.

The Sierra Leone transfer test

A feature is never labelled “best practice” merely because it works elsewhere. It must pass at least four questions:

  1. What mechanism appears to produce the benefit?
  2. Which enabling conditions does the mechanism depend on?
  3. Which of those conditions already exist in Sierra Leone, and which do not?
  4. What adaptation, cost or institutional change would be required?

Evidence standard

Country narratives are separated from verified evidence. Official policy is labelled as policy, implementation evidence as implementation evidence, expert interpretation as interpretation, and project hypotheses as hypotheses. The method is designed so disagreement can be recorded without forcing false consensus.
