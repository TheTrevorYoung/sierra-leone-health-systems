# Public Media Provenance Register

This register implements the portfolio-wide public visual media protocol for Sierra Leone Health Research.

## Rule
Publicly available media may be used as an interim live website asset only when reuse or embedding rights are sufficiently clear. Each asset must have a source, creator, rights status, placement, and replacement plan. Public visibility alone is not treated as permission.

## Duplication rule
The same Sierra Leone image should not be used repeatedly as generic decoration across many pages. Repetition is reserved for a small number of intentional anchor images where the same subject is being referenced. Route-specific imagery is preferred, and pages that already contain strong manual photography do not receive an additional automatic gallery.

## Replacement status
All third-party assets are interim unless promoted to permanent status after rights, relevance, quality and brand review. Original commissioned Sierra Leone photography/video should progressively replace the oldest and least representative Sierra Leone imagery first. Comparative country images may remain where provenance is strong and they accurately illustrate the research case.
